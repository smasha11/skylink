# Images

Photos are optimised automatically. **Don't drop raw photos here.** Put the original in
`_build/images-src/` and run `npm run images` (inside `_build/`). That creates a 1600px and an 800px WebP
here, plus `og-image.jpg`. Then upload the new `.webp` files.

| File | Where it's used | Original in `_build/images-src/` |
|---|---|---|
| `hero-trucks.webp` (+ `-800`) | Home hero | `hero-trucks.webp` |
| `driver-waiting.webp` (+ `-800`) | Home "you deliver the load… then the real problem starts" | `driver-waiting.png` (Weary Trucker at Sunset) |
| `highway-aerial.webp` (+ `-800`) | Transport page hero | `highway-aerial.png` (Sunset Highway Through the Savanna) |
| `port-containers.webp` (+ `-800`) | Trade page hero | `port-containers.jpg` |
| `warehouse-loading.webp` (+ `-800`) | About page hero | `warehouse-loading.jpg` |
| `founder.webp` (+ `-800`) | About page, founder story | `founder.jpg` (portrait crop of the photo you sent) |
| `og-image.jpg` | WhatsApp / Facebook / X link previews (made from the home hero) | — |
